# Droply — Прямая передача файлов между Android и MacBook по Wi-Fi

Полностью локальное приложение для быстрой двусторонней передачи файлов, текстовых заметок и целых папок любого размера между смартфоном Android и MacBook напрямую по Wi-Fi (без облачных и промежуточных серверов).

## Структура проекта
- `macOS/` — нативное приложение для macOS (Swift + SwiftUI + `DroplyCore` TCP streaming server)
- `Android/` — нативное приложение для Android (Kotlin + Jetpack Compose + Material 3 + CameraX + ML Kit QR Scanner)
- `website/` — лендинг проекта и страница установки (`downloads/Droply-Android.apk`, `downloads/Droply-macOS.dmg`)
- `docs/PROTOCOL.md` — спецификация бинарного протокола Droply v1.1

## Возможности
- **Прямой Wi-Fi без серверов:** поток данных идёт напрямую по локальному TCP-сокету только между Android и MacBook.
- **Подключение по QR-коду:** MacBook отображает QR-код (IP, порт, одноразовый токен сессии), Android сканирует его камерой и мгновенно подключается.
- **Шифрование и санитизация:** направленное шифрование `AES-256-GCM` с раздельными ключами `HKDF-SHA256`, защита от повтора пакетов и очистка имён файлов/путей от скрытых управляющих и Unicode-символов.
- **Целые папки потоком по 256 КБ:** передача файлов и каталогов с сохранением вложенной структуры, без сжатия качества, без лимита по размеру и с проверкой контрольной суммы `SHA-256`.
- **Непрерывная фоновая передача:** на macOS блокируются App Nap и системный сон во время передачи, а живой прогресс отображается в строке меню и прямо на иконке в Dock.
- **Текстовые заметки и согласие до записи:** встроенная отправка `.txt`-заметок в обе стороны и обязательное подтверждение приёма партии получателем.
- **Уведомления поверх окон:** плавающий баннер на macOS сообщает о завершении загрузки без перехвата фокуса.

## Установка готовых сборок
Готовые сборки лежат в папке `website/downloads/`:
- **Android (`23 МБ`):** `website/downloads/Droply-Android.apk` (Android 8.0+)
- **macOS (`2.3 МБ`):** `website/downloads/Droply-macOS.dmg` (macOS 14+, Apple Silicon)

## Запуск из исходников на MacBook
```bash
cd macOS
./build_app.sh
open build/Droply.app
```
Проверка тестов ядра и протокола:
```bash
cd macOS
swift test --disable-sandbox
```

## Сборка для Android
Откройте папку `Android/` в **Android Studio** (JDK 17+, Android SDK 35) или соберите из терминала:
```bash
cd Android
./gradlew assembleRelease
```
Оба устройства должны находиться в одной сети Wi-Fi.

## Локальный просмотр сайта
```bash
cd website
python3 -m http.server 8765
```
Откройте в браузере `http://localhost:8765/`.
